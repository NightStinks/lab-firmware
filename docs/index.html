Setting up a new sensor

  1. Plug it in where it will live. After a few seconds it makes its own Wi-Fi network: LAB Presence Setup or LAB Zones Setup.
  2. On your phone, join that Wi-Fi. A page opens by itself: choose your home Wi-Fi and type its password.
  3. Wait a minute while it joins your Wi-Fi. The setup network disappears.

If the sensor is plugged into a computer, you can do the same over USB from the install page: connect, skip the install, and enter your Wi-Fi there.

Home Assistant

Home Assistant finds the sensor on its own and shows New device discovered. Press Add to get its sensors (Presence, Moving, Still, or the zones) in Home Assistant.

The LAB. app lists every LAB. sensor and opens its setup page from the Home Assistant sidebar, including away from home. See Home Assistant setup for both, with one-click buttons.

The sensor's own page

Each sensor serves its own setup page, which works without internet and without Home Assistant. Open it from the LAB. app, or go to its address in a browser on the same Wi-Fi:

  • LAB. Presence: http://lab-presence-xxxxxx.local
  • LAB. Zones: http://lab-zones-xxxxxx.local

The last six characters are unique to each sensor. Home Assistant shows them in the device name.

LAB. Presence

Set Sensitivity, Detection range and Clear delay. Learn my room measures the empty room for 60 seconds and sets the thresholds just above it: leave the room, and keep the page open until it finishes.

LAB. Zones

Choose where the sensor is mounted (on a wall, or in a corner at 45 degrees), then paint named zones and ignore areas on the map. Settings and the map can be saved to a file and restored.

Updates

Sensors check for new firmware every 6 hours. When there is one, Home Assistant shows Update available on the sensor's Firmware entity. Nothing installs until you press Install.

After an update, leave the sensor running for a minute before restarting it. A new version is only kept once it has run for about a minute; restarting sooner goes back to the previous version.

Moving a sensor

Just plug it in at the new place. If it cannot find its saved Wi-Fi for a minute (90 seconds for LAB. Presence), the setup network comes back on its own, so you can join it and choose the new Wi-Fi.

Factory reset

LAB. Zones

Plug it in and unplug it again within 10 seconds, five times in a row. Wi-Fi, the map and every setting are erased, and it restarts into its setup network.

LAB. Presence

Plug it into a computer and reinstall from the install page, choosing to erase the device when asked.

Troubleshooting

I cannot see the setup network

Stand close to the sensor. Wait 30 seconds after plugging it in. Try a different USB power adapter, since weak ones can stop the Wi-Fi starting. If it was set up before, it only makes the setup network after failing to reach its saved Wi-Fi for a minute or so.

The sensor's page will not open

Make sure you are on the same Wi-Fi. Some networks block .local names: open it from the LAB. app instead, or use the IP address shown in Home Assistant or your router.

The install page cannot find the sensor

Use Chrome or Edge on a computer. Try another USB cable, as many only charge. If the port still does not appear, hold the BOOT button on the board while plugging it in.
