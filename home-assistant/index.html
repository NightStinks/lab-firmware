Home Assistant

Two parts. The LAB. app is added once per home. Each sensor is added once, and Home Assistant usually finds it for you.

The buttons open your own Home Assistant through My Home Assistant. The first time, it asks for your Home Assistant's address.

Once per home

Add the LAB. app

Lists every LAB. sensor and opens its setup page from the Home Assistant sidebar, including away from home.

Add LAB. to Home Assistant Add the repository only
  1. Press Install. The first install takes a few minutes.
  2. Press Start, and turn on Show in sidebar.

Apps need Home Assistant OS, which most people use. On Home Assistant Container, skip this part: the sensors still work, and their pages open from their own address (see Docs).

Each sensor

Add your sensors

Once a sensor is on your Wi-Fi, Home Assistant shows New device discovered. Press Add. Its presence and zone sensors, settings and firmware updates appear on the device.

See discovered devices Add by address instead

If it is not discovered, use Add by address with the sensor's address, for example lab-zones-a1b2c3.local or its IP.

Sensor not on Wi-Fi yet? See Setting up a new sensor.
