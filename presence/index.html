Install LAB. Presence

The LD2410 presence sensor. For the LD2450 multi-zone sensor, use LAB. Zones.

This browser cannot talk to USB devices. Open this page in Chrome or Edge on a computer.
Installing only works over a secure (https) connection.

Steps

  1. Plug the sensor into this computer with a USB cable.
  2. Press Connect sensor, choose its USB port, then Install.
  3. When it finishes, enter your Wi-Fi name and password.
  4. Home Assistant finds the sensor on its own. Press Add when it says New device discovered.
Next: add LAB. to Home Assistant to open the sensor's setup page from the sidebar.

If the port does not show up

  1. Try another cable. Many USB cables only charge and cannot carry data.
  2. Hold the BOOT button on the board while plugging it in, then try again.

manifest.json is the firmware feed. Installed sensors check it every 6 hours.
